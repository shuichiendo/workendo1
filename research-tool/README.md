# workendo 商品発掘テストツール

NETSEAの直送対応商品を「利益が出るか」「売れそうか」で**自動採点・ランキング**するテストツールです。
既存のショップサイトとは独立した、社内向けの発掘ツールです。

## できること

- 候補商品を読み込み、販売チャネル別に**全コストを引いた粗利率・粗利額を自動計算**
- 提案書の評価軸（収益性30/需要20/競争15/供給15/運用規約20）で**100点採点**
- **A/B/C/D 判定**で採用ラインを自動抽出（「採用ラインのみ」表示でA・Bだけに絞れる）
- キーワード・カテゴリ・目標粗利率・広告費率・直送可否でリアルタイム絞り込み
- 商品ごとに利益内訳とスコア内訳を展開表示

## 動かし方

```bash
cd research-tool
python3 -m http.server
# → http://localhost:8000
```

## ⚠️ データの取得方法（重要）

**ログインID/パスワードでの自動スクレイピングは行いません。** NETSEA利用規約に抵触し、
アカウント停止のリスクがあるためです（実際にサイトは機械アクセスを403で拒否します）。

正規のデータ取得ルートは次の2つ：

### 1. NETSEA バイヤーAPI（推奨）
- NETSEAマイページ →「登録情報管理」→ API登録情報 → 利用規約に同意して**申請**
- 発行される **APIキー** を使う（※パスワードではない。環境変数=秘密として扱う）
- APIでは「**消費者直送可＋取引承認済みサプライヤー**」の商品だけが取得可能 → まさに直送候補だけが取れる
- ドキュメント: https://api.netsea.jp/docs/buyer/

### 2. CSVダウンロード
- NETSEAの「商品データダウンロード」機能でCSVを取得し、下記形式に変換して差し込む

## データ形式（`data/candidates.json`）

APIやCSVから取得したデータを、この形式の `products` 配列に変換して置き換えます。

| フィールド | 意味 |
|---|---|
| `netsea_id` | NETSEA商品ID（直送可・承認済みのみ） |
| `wholesale` | 卸価格（仕入原価） |
| `ship_cost` | 仕入送料（直送時の送料負担） |
| `market_price` | 想定販売価格（市場相場） |
| `stock_qty` | 在庫数 |
| `dropship` | 消費者直送対応か（true/false） |
| `returnable` | 返品対応可否 |
| `ship_days` | 標準出荷日数 |
| `demand_index` | 需要の代理指標（0-100） |
| `competitor_count` | 競合出品者数の目安 |
| `supplier_score` | サプライヤー信頼度（0-100） |

> `market_price`（相場）と `demand_index`/`competitor_count`（需要・競合）は、APIの商品情報だけでは
> 取れないため、市場照合（Amazon/楽天/Google等の公開価格・件数）を別途組み込む拡張ポイントです。
> まずはAPIで取れる価格・在庫・直送可否で「収益性」を自動判定し、需要・競合は後から精度を上げます。
