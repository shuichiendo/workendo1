# workendo — ドロップシッピング ショップ雛形

ネッシー（NETSEA）の商品を扱うドロップシッピング用のショップサイト雛形です。
HTMLとJSONだけで動く静的サイトなので、そのまま無料ホスティング（GitHub Pages 等）に載せられます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ショップ本体（トップ・商品グリッド・詳細モーダル・カート） |
| `products.json` | 商品データ。ここを編集するだけで品揃えを変えられます |
| `archive/petit-food/` | 以前の料理教室サイト（退避） |

## 動かし方

```bash
# ローカルで確認（file:// では商品が読めないので簡易サーバー経由）
python3 -m http.server
# → http://localhost:8000 を開く
```

## 商品の入れ替え方（ネッシー商品の登録）

`products.json` の `products` 配列を編集します。1商品 = 1オブジェクト。

```json
{
  "id": "P001",                    // 任意の商品ID
  "name": "商品名",
  "category": "interior",          // categories の id と対応
  "price": 2480,                   // 販売価格（税込）
  "cost": 980,                     // 仕入れ値（ネッシー価格・利益計算用メモ）
  "netsea_id": "0000000",          // ネッシーの商品番号（発注時の控え）
  "dropship": true,                // 直送(ドロップシッピング)対応かどうか
  "stock": true,                   // 在庫あり=true / 欠品=false
  "color": ["#d9c9b3", "#b5a68f"], // 画像未設定時のプレースホルダー色
  "tags": ["新着", "送料無料"],
  "description": "商品説明"
}
```

> **重要:** ネッシーで直送できるのは「ドロップシッピング対応」商品だけです。
> 商品を選ぶ際は必ず直送可否を確認してください。
